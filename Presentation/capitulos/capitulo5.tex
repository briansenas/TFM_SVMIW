\subsection{Conclusiones}
\begin{frame}
  \frametitle{Conclusiones}
  \begin{enumerate}
    \item Se realizó un estudio de la literatura de metrología monocular.
    \item Se hizo una comparativa entre métodos de diferentes características.
      \begin{itemize}
        \item Método clásico de calibración de escena.
        \item Método estático de referencia.
        \item Método por aprendizaje profundo.
      \end{itemize}
    \item Se observa el potencial del método por aprendizaje de automatizar tareas de metrología.
    \item Se dispone de una implementación de~\footcite{SVMIW}, abriendo puertas trabajos futuros.
    \item Se identifica las limitaciones y posibles futuras investigaciones.
    \item \url{https://github.com/briansenas/TFM_SVMIW}
  \end{enumerate}
\end{frame}
